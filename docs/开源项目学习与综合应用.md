# 开源项目学习与综合应用

本项目不复制大型开源系统，而是学习它们的边界和工程方法。

## RAGFlow

- 仓库：<https://github.com/infiniflow/ragflow>
- 学习：文档摄取、切片、索引、引用和检索流程
- 应用：将当前同步/简单检索逐步演进为可追踪的 ingestion job 和引用链路

## Dify

- 仓库：<https://github.com/langgenius/dify>
- 学习：知识库、模型、应用、会话和日志的产品化组织
- 应用：增加运维知识库、诊断记录、审计和模型配置的控制面

## Haystack

- 仓库：<https://github.com/deepset-ai/haystack>
- 学习：Retriever、Fusion、Reranker、Generator 的组件化 Pipeline
- 应用：让关键词检索、向量检索、重排序和诊断生成能够独立测试和替换

## LlamaIndex

- 文档：<https://developers.llamaindex.ai/python/framework/understanding/rag/>
- 学习：Document、Node、Metadata Filter
- 应用：按 GPU 型号、CUDA 主版本、文档类型、严重级别和权限过滤运维资料

## Prometheus

- 仓库：<https://github.com/prometheus/prometheus>
- 学习：时间序列指标、标签、抓取和告警模型
- 应用：为 GPU 温度、显存、利用率、XID 错误和采集状态预留标准字段，不把指标伪装成真实监控数据

## NVIDIA DCGM Exporter

- 项目主页：<https://github.com/NVIDIA/dcgm-exporter>
- 学习：GPU 指标暴露、Prometheus 抓取和数据中心 GPU 监控
- 应用：下一阶段在 Linux + NVIDIA Container Toolkit 环境中接入，不在 Windows 本机强行模拟

## Grafana

- 仓库：<https://github.com/grafana/grafana>
- 学习：指标可视化、Dashboard 和告警展示
- 应用：后续提供 GPU 主机利用率、显存、温度和错误趋势面板

## 综合落地原则

```text
MySQL：资产、权限、文档、任务、诊断记录、审计
RAG：运维手册和故障知识的检索、引用、诊断编排
nvidia-smi/DCGM：GPU 事实指标
Prometheus：时间序列指标
Grafana：趋势与告警可视化
```

面试时必须区分“已在本机验证”“已设计接口”“计划接入”。
