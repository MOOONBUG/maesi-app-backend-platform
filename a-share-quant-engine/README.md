# A-Share Quant Engine

> 面向 A 股市场的纯 Node.js 事件驱动量化回测底座，集成双源行情降级、ETF 唐奇安趋势跟随、ATR 动态头寸管理、账户硬风控与 ECharts 交互式报告。

## 项目概述

本项目是一套不依赖 Python 第三方量化框架的 A 股量化回测引擎。系统以逐根 K 线事件驱动回测为核心，通过策略层消费标准化行情数据，模拟交易、持仓、现金、手续费、滑点和风控状态，并输出可在浏览器中查看的 HTML 报告和 JSON 明细。

当前策略采用 ETF 唐奇安通道趋势跟随模型：以历史价格突破识别趋势，以通道下轨和 ATR 移动止损控制退出，并根据波动率动态约束单笔交易风险。

## 核心架构

项目按职责拆分为三层：

```text
行情数据获取层  →  策略计算层  →  回测结果与可视化展现层
 data_loader.js       strategy.js       backtest.js
```

### 1. 数据获取层：双源降级容灾

`data_loader.js` 负责历史日线与 15 分钟行情的获取、清洗、去重和排序：

- 优先请求东方财富行情接口；
- 当主数据源不可用时，自动降级至腾讯财经接口；
- 将行情统一转换为策略层使用的标准 OHLCV 结构；
- 对异常 K 线、重复日期和无效成交量进行清洗；
- 不把具体数据源耦合进策略信号判断。

### 2. 策略计算层：指标与交易逻辑解耦

`strategy.js` 负责：

- 计算唐奇安通道和 ATR 等技术指标；
- 根据历史 K 线事件产生开仓、平仓信号；
- 根据 ATR 波动率计算风险头寸；
- 维护现金、仓位、成本、止损线和交易记录；
- 将交易原因写入交易明细，供报告层展示。

指标计算和策略执行分离，使数据管道、策略模型与回测引擎可以独立演进。

### 3. 可视化展现层：ECharts 双 Y 轴交互报告

`backtest.js` 负责组装回测流程并生成：

- `backtest_report.json`：结构化回测数据与交易明细；
- `backtest_report.html`：可直接在浏览器打开的 ECharts 交互报告；
- 策略净值、沪深 300 基准和 ETF 价格曲线；
- 双 Y 轴展示净值/指数与标的价格；
- 支持缩放、悬停、图例切换；
- 买入、卖出标记及对应风控触发原因提示；
- 回测收益、年化收益、最大回撤、夏普、胜率、盈亏比和交易次数统计。

## 工业级风控引擎

> 风控优先于收益。策略信号只能提出交易意图，所有订单都必须经过账户级和持仓级风控约束。

- **账户 8% 硬熔断**：账户净值相对历史权益峰值回撤达到 8% 时，立即停止新增交易并平掉当前持仓。
- **单日 8% 跌幅强制平仓**：持仓标的相对前一交易日收盘价下跌达到 8% 时，触发强制退出。
- **ATR 动态移动止损**：根据当前 ATR 动态维护止损价格，止损线只上移、不下移，适应不同波动率环境。
- **T+1 可用持仓冻结**：买入当日持仓不可卖出，避免回测违反 A 股交易制度。
- **1% 单笔风险头寸约束**：按照账户现金的 1% 作为单笔风险预算，并使用 ATR 估算风险单位，使波动越大的标的下单数量越少。
- **交易成本约束**：回测显式计入佣金、印花税和滑点，避免收益结果脱离实际成交条件。

## 快速开始

### 环境要求

- Node.js 18 或更高版本；
- 可访问行情数据接口的网络环境；
- Windows PowerShell、macOS Terminal 或 Linux Shell 均可运行。

### 安装与运行

项目仅使用 Node.js 内置模块，不需要安装额外依赖：

```bash
npm run backtest
```

等价命令：

```bash
node backtest.js
```

### 输出结果

执行完成后，项目根目录会生成或更新：

- `backtest_report.html`：双击即可在浏览器中打开的交互式 ECharts 回测报告；
- `backtest_report.json`：包含策略配置、净值序列、交易记录、买卖点和风控原因；
- 终端表格：输出各 ETF 的总收益、年化收益、最大回撤、夏普比率、胜率、盈亏比和交易次数。

如果主行情源不可用，终端会记录降级提示并尝试使用腾讯财经数据源。公开行情接口可能存在延迟、限流或临时不可用情况。

## 风险提示

本项目用于量化研究、策略验证和工程演示，不构成投资建议。历史回测结果不代表未来收益。实盘使用前，应进一步验证成交可得性、ETF 流动性、复权处理、交易时段、申赎机制、滑点模型和样本外表现。
