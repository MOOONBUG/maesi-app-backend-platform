一、知识库文档录入与清洗规范

1.文本切片长度：建议将单段切片控制在 300 至 500 字之间，每段之间保留 50 字左右的重叠上下文，防止核心句意在切分处断裂。

2.表格与结构化数据：避免直接粘贴复杂跨行表格，建议将其转换为 Markdown 表格或逐行 JSON 键值对格式录入，以保证向量化时的语义完整。

3.文本杂质过滤：录入前需清理无效的页眉页脚、页码、乱码字符及无意义的重复样式代码。

二、检索与模型调用优化

1.关键词与语义混合检索：生产环境不建议仅依赖单一向量检索，需结合传统关键字检索与重排序模型，提升特定专业术语和编号的召回率。

2.边界控制与未命中兜底：当检索匹配度低于设定阈值时，必须通过系统提示词约束模型回答未检索到相关内容，严禁大模型盲目发挥或伪造业务事实。

3.系统人设锁定：系统提示词中须固定企业品牌身份，屏蔽底层大模型默认自我介绍，防止身份暴露。

三、数据安全与权限管控

1.元数据权限打标：每篇入库文档必须标记对应的部门权限标识，在向量检索阶段进行底层过滤，防止跨部门越权查询。

2.敏感信息拦截：上线前须配置敏感词过滤与隐私数据拦截机制，对身份证号、手机号、密钥等敏感字段进行脱敏处理。

3.接口鉴权与限流：对外提供的 API 必须开启统一的 Token 鉴权，并针对客户端 IP 配置合理的每分钟请求频次限制。

四、运维与监控维护

1.进程与端口管理：服务部署或更新时，须确保旧进程已彻底退出再释放端口，避免端口冲突导致 API 启动异常。

2.流式响应并发：后端调用大模型 API 时必须采用全异步客户端处理，防止耗时较长导致 Python 主线程阻塞。

3.评价反馈追踪：系统应记录用户的点赞与点踩反馈，定期导出低质量回答数据，用于补充知识库及优化提示词。
